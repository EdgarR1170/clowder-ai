# Novel Humanizer (ZH) — 中文网文去 AI 味精修规范

## 为什么需要专门去 AI 味

大模型直出的中文小说常见五大顽疾：
1. **五官套话成瘾**：“嘴角勾起一抹不易察觉的弧度”、“眼底闪过一丝复杂的精芒”、“空气仿佛在这一刻凝固”；
2. **机械三连排比**：“不是A，也不是B，而是C”；
3. **解释型副词泛滥**：“不由自主地”、“情不自禁地”、“仿佛在诉说着”；
4. **句式等长催眠**：每句都是 18~22 字的主谓宾完整句，缺少口语省略、短句顿挫与留白；
5. **段尾哲理升华**：“他知道，属于他的风暴才刚刚开始”。

## 精修四条铁律

1. **读诊断锚点**：先看系统 `humanizerReport` 标出的命中段落与 `aiFlavorScore`，逐处定点拔除套话。
2. **情绪转动作/物象**：把“心中涌起一股悲凉”改为“指节抵着发凉的刀鞘，半晌没松开”；把“空气凝固”改为具体的灯花爆裂或呼吸停滞。
3. **打破等长句节拍**：动作与对峙处果断切 4~10 字短句；对话删掉多余的“他缓缓开口说道”，善用动作接台词。
4. **绝对零事实篡改**：人物生死、位移、获得/消耗的物品与面板数值必须与原稿 100% 一致，润色完调用 `novel_submit_chapter_draft(draftKind="humanized")` 提交（系统自动保留 `raw` 原稿备份供双栏对比）。

## Common Mistakes

| 错误 | 后果 | 修复 |
| :--- | :--- | :--- |
| 为了去 AI 味过度文青化，把爽快网文改成晦涩现代诗 | 阅读门槛暴增，丢失叙事推进力 | 遵循项目 `StyleProfile` 的目标句长与通俗流畅度，重在干净利落 |
| 润色时顺手把章末钩子圆回来写满了 | 悬念消失 | 保持章末在最勾人的一拍戛然而止 |

## 和其他 Skill 的区别

- `novel-critic-gate`：审查剧情、穿帮与结构评分；本技能专注在结构过关后打磨中文语感与活人呼吸感。
